# Natural Kolkata Bengali voice research

Research checked 15 October 2026. An offline neural speech path was subsequently found and tested; see the offline section below.

## Result

The old recordings are eSpeak formant speech. They are not natural Kolkata Bengali and should not be labelled or offered as that improvement. Real neural Indian Bengali samples were generated successfully with Piper, entirely offline, after the provider check.

No speech-provider environment variable names were present in the inspected process, no project `.env` file was found, and no Azure/gcloud CLI or their usual local configuration directories were found. No connected audio-generation tool was exposed. Secret values were not printed. The earlier attempt to generate through the public Edge Read Aloud endpoint returned HTTP 403; this is not an authenticated Azure Speech connection.

Commercial neural generation would require an authenticated, authorised service. However, the working open model below avoids that requirement. Exact Kolkata accent verification still requires a native listening review or licensed recordings by Kolkata Bengali speakers. Service credentials, if used later, must be configured securely, never committed or put in browser JavaScript. Static MP3s require no runtime API keys or paid per-visitor calls.

## Working offline neural model

The official [Rhasspy Piper model card](https://huggingface.co/rhasspy/piper-voices/blob/main/bn/bn_BD/google/medium/MODEL_CARD) explicitly includes both Indian and Bangladesh Bengali source speakers. The model is a 76,782,515-byte ONNX neural VITS model with 16 speakers. Its directory is named `bn_BD`, so choosing the default voice would not establish Indian Bengali provenance.

Indian source speakers were independently identified by reading the central directory of Google's [Indian Bengali TTS archive](https://www.openslr.org/resources/37/bn_in.zip), using a small HTTP range request rather than downloading the corpus. The archive contains `bin_<speakerID>_*.wav` for source IDs `0834`, `1010`, `3108`, `3713`, `3958`, `4046`, `4811`, `5958` and `9169`. In the official Piper configuration these map to numeric speaker IDs 6 through 14 respectively. Source 1010 (Piper 7) and 4811 (Piper 12) provide distinct lower/higher character voice presentations. Upstream metadata does not label those performers' genders; no pitch shift is used.

Nine actual samples were successfully synthesised using Piper 1.8.0 and ONNX Runtime on the existing CPU environment. A 5–7-second sample took approximately 0.5–0.7 seconds to generate after a roughly 1.3-second model load. This is an observed local measurement, not a cross-device benchmark. The 34 MB Windows Piper runtime and 77 MB model stay outside the shipped Site; visitors receive compressed recordings only. eSpeak is used only for text-to-phoneme conversion inside Piper, while the audible waveform is generated by the neural model. It does not reuse the rejected eSpeak speech recordings.

Google's [OpenSLR37 page](https://www.openslr.org/37/) identifies a dedicated Indian Bengali TTS corpus and supplies CC BY-SA 4.0 licensing. Preserve that license, Google attribution and the original model card including its CMU license notice. New generated voice media are offered under CC BY-SA 4.0. Model/source provenance establishes Indian Bengali, not a certified Kolkata accent or individual speakers' hometowns.

The larger Coqui `bn/custom/vits-male` and `vits-female` models are alternatives: [Coqui's model registry](https://github.com/coqui-ai/TTS/blob/dev/TTS/.models.json) lists Apache 2.0 and their creator's [training repository](https://github.com/mobassir94/comprehensive-bangla-tts) says they use IITM IndicTTS. The official release API lists 916,904,237 and 918,141,611 bytes respectively, so the compact Piper model was preferred. The [IITM consortium paper](https://www.tsdconference.org/tsd2016/download/cbblr16-850.pdf) credits CDAC Kolkata for Bengali corpus collection. That institutional link does not certify each training speaker's hometown. No Coqui model or runtime was installed.

OpenSLR53 is a Bangladeshi Bengali **ASR** corpus, not the Indian Bengali TTS corpus. It was not used.

## Primary-source findings

- Microsoft documents Bengali India voices `bn-IN-TanishaaNeural` (female) and `bn-IN-BashkarNeural` (male). See the [Microsoft-maintained voice support table](https://github.com/MicrosoftDocs/azure-ai-docs/blob/main/articles/ai-services/speech-service/includes/language-support/tts.md). The [REST API documentation](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech) requires a Speech resource key or access token for synthesis.
- Google documents Bengali India premium voices, including `bn-IN-Chirp3-HD-Achernar` (female), `bn-IN-Chirp3-HD-Achird` (male), and `bn-IN-Wavenet-A/B/C/D`. See [Google's voice catalogue](https://docs.cloud.google.com/text-to-speech/docs/list-voices-and-types). Its [authentication documentation](https://docs.cloud.google.com/text-to-speech/docs/authentication) describes authenticated API access using Google Cloud credentials.
- ElevenLabs advertises [Bengali speech and regional accent support](https://elevenlabs.io/text-to-speech/bengali), but that page does not verify a named Kolkata accent voice. A Bengali language claim is insufficient to select an authentic Kolkata performance without listening and review.

None of these primary sources certifies that a `bn-IN` label alone means a verified Kolkata accent. An actual listening review by a Kolkata Bengali speaker is needed before making that claim. Do not substitute `bn-BD` or infer accent from pitch.

## Honest interim browser behaviour

If browser speech is used, select only an installed Bengali India (`bn-IN`) voice and say that voice availability depends on the visitor's device. Prefer recognised natural male/female voices by their real names; do not pitch-shift one voice to create a second gender. If matching voices are absent, keep the Bengali text and English translation available and explain that spoken dialogue is unavailable on that device. This is a device-voice fallback, not delivery of a verified Kolkata-accent recording.

Do not silently fall back to English, Hindi, Bengali Bangladesh, or the old eSpeak MP3s. Keep dhak ambience independent of dialogue availability.
